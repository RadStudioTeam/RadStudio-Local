# 已发布算子定义不可变

## 使用规则

当前注册接口创建后即 available，视为发布；尚未实现自定义算子的草稿/构建/验证生命周期。已有 available/deprecated 记录也受保护，不要求重新注册。

以下变更必须注册新版本：类型/版本、参数Schema、默认值、输入输出（含语义契约）、入口、运行时类型/端点/镜像、资源要求。旧工作流保持原版本，不自动升级。

名称、分类、说明可以修改；认证Token可以轮换，留空保持原值。凭据不属于公开的语义身份，也不得放入导出摘要。归档版本仍禁止全部编辑与恢复。

后台编辑已将语义字段设为只读；直接API改写返回409。状态下线/恢复单独操作，不改变定义。

## 开发与存储

迁移 042_operator_immutable 添加 BEFORE UPDATE OR DELETE 触发器，对数据库 JSON 语义比较，拒绝定义变更及物理删除；SQLSTATE 55000映射为ErrOperatorImmutable。内存仓储使用同等字段集合比较。数据库层保护同时涵盖版本主键、创建来源，拒绝跳过下线直接归档和归档后任何实际修改。内存/PG 仓储也拒绝类型版本改写及非法状态目标，PG 零行更新的已归档冲突与不存在记录区分。数据库拥有者仍可通过 DDL 改变保护，这不是对数据库超级用户的隔离边界。

认证Token轮换不会更改执行绑定，但端点地址变更需要新版本。后续独立执行绑定/密钥管理若放宽这项规则，必须通过明确迁移和版本化规范，不能绕开触发器。

当前未提供运行级算子/环境快照，不据此宣称完整可复现；正在运行或待执行任务对凭据与部署状态的依赖仍需后续快照与执行绑定设计解决。

## 注册中心引用隔离补充

迁入快照前审查发现内存仓储只复制最外层结构，调用方可在读取后直接修改嵌套 Schema、默认值、数组或端口契约，绕过 Update 的不可变检查；Create 也允许不同 type/version 通过相同 ID 覆写原记录。这两条绕过均已修复。

克隆前拒绝不可编码 JSON/循环值，随后深复制可变容器及指针，保留原生数值类型、json.Number 和操作凭据。没有使用普通 JSON 解码把大整数或高精度小数转成 float64。Create 先检查已有 ID 并返回 ErrOperatorExists，非法定义不能落库。六种读取入口（ID、type/version、全部、可用、新目录、按类型）和注册后调用方修改都覆盖引用隔离；同时断言 9007199254740993 和 0.10000000000000001 不变。

本补充只修复注册中心值的持有/返回边界，不宣称已有运行已持有完整快照。当前分支 Go 全量（PG/Redis、专用 AI 持久化）12.534s 及 vet 通过。快照摘要、持久化数值往返与重试冻结校验仍需后续接入。
