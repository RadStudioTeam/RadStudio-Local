# 术语表

按字母与主题混排，优先给出在本平台语境下的含义。

## A–D

**Artifact（产物）**
运行过程中由节点生成并登记的文件，如指标 JSON、图表、模型、报告。产物可下载，也可被下游节点引用。

**AI Token**
模型输入与输出文本的计量单位。套餐按周期提供额度，超出部分按单价从组织积分扣除。

**BindToken**
微信小程序未绑定账号登录时签发的一次性凭证（10 分钟），只能用于绑定流程，不能当作访问令牌。

**Credits（积分）**
平台统一的计量与结算单位，用于计算资源与 AI 超额用量。

**Data Collection（数据集合）**
项目内一张可编辑的样本表，每行代表一个样本、时间点或单细胞文库，行内用角色绑定资源文件。集合带修订号。

**Reader Config（读取配置）**
读取节点的参数集合，按修订保存。运行时记录实际使用的配置修订。

**Input Snapshot（输入快照）**
运行提交时固化的集合修订、读取配置修订与文件清单。之后修改数据不会改写历史运行的输入记录。

**DLCNNTraining / DLCNNInference**
深度学习训练与推理算子，支持 torchvision 与 MONAI 骨干。

## E–L

**External Validation（外部验证）**
用独立数据集评估已训练模型，与 OOF（交叉验证折外预测）相对。

**Ledger（积分流水）**
组织积分的增减记录，包括充值、发放、运行扣费、失败返还与兑换。

## M–R

**OOF（Out-of-Fold）**
交叉验证中每个样本由未在训练中见过它的模型给出的预测，用于无偏评估。

**Operator（算子）**
工作流中的可执行单元，有类型、版本、参数与输入输出端口。

**Operator Version（算子版本）**
某个算子类型的具体版本，发布后不可变。

**Org（组织）**
计费与配额的主体，持有积分、套餐、成员与项目。用户通过成员关系获得组织权限。

**QC（Quality Control）**
样本质量检查，状态包括 accepted / warning / blocked / excluded。

**Run（运行）**
工作流的一次执行实例。状态为 pending / running / completed / failed / cancelled。

**Run Node（运行节点）**
运行中某个算子的执行状态，终态为 succeeded / failed / cancelled / skipped，终态不可回退。

## S–Z

**WeChat Binding（微信绑定）**
小程序账号与既有 Web 账号的绑定关系。未绑定账号不能访问任何业务数据。

**Workflow（工作流）**
由节点与边组成的有向无环图，描述从数据输入到结果输出的完整分析流程。

**Workflow Share（工作流分享）**
站内分享机制，通过链接或分享码复制工作流；工作流定义不会下发给未授权用户。
